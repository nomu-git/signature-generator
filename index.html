How to add this to Microsoft Outlook

New Outlook for Windows & Outlook on the web outlook.office.com

  1. Click Copy signature above.
  2. In Outlook, open Settings (gear icon, top right) → Accounts → Signatures.
  3. Click + New signature and name it, e.g. NomuHub.
  4. Click inside the editor box and press Ctrl+V (Cmd+V on Mac).
  5. Under Select default signatures, pick it for New messages and Replies/forwards, then click Save.

Classic Outlook for Windows desktop app

  1. Click Copy signature above.
  2. In Outlook, go to File → Options → Mail → Signatures…
  3. Click New, type a name (e.g. NomuHub), then click OK.
  4. Click inside the Edit signature box and press Ctrl+V.
  5. On the right, set New messages and Replies/forwards to the new signature, then click OK.

Outlook for Mac

  1. Click Copy signature above.
  2. In Outlook, go to Outlook → Settings → Signatures.
  3. Click +, name it, click inside the editor and press Cmd+V, then save.
  4. Under Choose default signature, set it for new messages and replies/forwards.

If something looks off

  • Copy from Microsoft Edge or Google Chrome. Some browsers drop the formatting or the logo when copying.
  • Paste with a plain Ctrl+V. Don't use "Paste as plain text" or Ctrl+Shift+V.
  • If the logo is missing in classic Outlook, check File → Options → Mail → Compose messages in is set to HTML.
  • The Outlook mobile app (iOS/Android) only supports plain-text signatures. Type your name, title and WhatsApp number there by hand.
